ALI GAZAL SITE — BAŞLANGIÇ

Amaç:
YouTube videolarını destekleyen ücretsiz uygulama ve rehber merkezi.

Dosyalar:
- index.html        Ana sayfa
- rehberler.html    Ücretsiz rehberler
- hakkimda.html     Projenin amacı
- styles.css        Görünüm

Şimdilik yapılmayacaklar:
- Üyelik / kullanıcı hesabı
- Ödeme
- Veritabanı
- Premium içerik
- Karmaşık framework

Laptopta görmek için:
1. ZIP dosyasını çıkar.
2. Klasörde index.html dosyasına çift tıkla.
3. Firefox'ta site yerel olarak açılır.

Sonraki küçük adım:
