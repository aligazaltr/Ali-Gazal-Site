Its area centroid is (934.229732, 407.262155) in the shared SVG coordinate system; it is not the entire numeral's bounding box center. The license is retained alongside this document. Runtime requires no font download or image. The actual counter boundary is sampled once per layout measurement. A conservative inscribed radius defines zoom from viewport coverage; only after coverage does the now-offscreen foreground disappear.
